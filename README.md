### 🟣 Finora — Personal Finance Dashboard

> **A modern, local-first finance dashboard — extended and deployed from an upstream open-source project.**

React · TypeScript · Vite · Tailwind CSS · Recharts · React Router

**My contribution to this fork:**
- Replaced the static secret gate with a **local PIN authentication** flow
- Added **cross-device sync** through an encrypted data file
- Corrected silent auth failures so errors surface properly
- Deployed to **GitHub Pages**; improved **docs** and **secret handling**; removed demo data

→ [Live demo](https://deepankar-siddharth.github.io/finora/) · [Source](https://github.com/Deepankar-Siddharth/finora) · [Upstream project](https://github.com/nayra-singh/finora)

---

### 🔵 Instant Ledger — Privacy-First Android Finance Ledger

> **An offline-only Android ledger that captures transactions automatically from bank SMS — nothing leaves the device.**

Kotlin · Jetpack Compose · Room · SQLCipher · Hilt · WorkManager · Material 3

**What it does**
- Parses bank SMS on-device (SBI, HDFC, ICICI, Axis, Kotak, PNB, BOI)
- Pending → categorized → approved transaction workflow
- **SQLCipher-encrypted** database · biometric + PIN lock
- CSV / JSON export · password-protected backups
- No accounts, no analytics, no network required

→ [View repository](https://github.com/Deepankar-Siddharth/instant-ledger)

---

### 🟠 Event Sphere — Full-Stack Event Management

> **An event management system wiring bookings, staffing, packages and payments into one application.**

React · Node.js · Express · MySQL · JWT

**What it does**
- Event booking & user management (admin / employees / customers)
- Package & service management
- Payment and invoice workflows · reports & analytics
- JWT-based authentication · REST API with `/api-docs`

→ [View repository](https://github.com/Deepankar-Siddharth/event-sphere)

---

### 🔴 Temp-RDP — On-Demand Remote Environments

> **One-click ephemeral Windows RDP environments built on GitHub Actions and ngrok tunneling.**

GitHub Actions · Batch/Shell · ngrok · Windows RDP

**What it does**
- Provisions a temporary accessible Windows environment on demand
- Automated setup, monitoring and teardown via a workflow
- Built for testing and development — the most-forked repository in this profile

→ [View repository](https://github.com/Deepankar-Siddharth/Temp-RDP)

## `05` — Engineering Philosophy

`// rules I try to write software by`

```text
01  If a task repeats, automate it.
02  If data matters, make ownership explicit.
03  If a system is complex, make the boundaries clear.
04  If a feature isn't useful, don't add it just for the demo.
05  Build for the person who has to use and maintain it later.
```
